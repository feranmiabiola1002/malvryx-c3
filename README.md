# ☠️ Malvryx C2 — Command & Control Panel

A lightweight, serverless C2 (Command & Control) panel deployed on Vercel.

## Features

- 🔐 Admin Login Protection
- 📡 Multi-agent support
- 🎮 Command dashboard
- 📷 Camera capture
- ⌨️ Keylogger control
- 🌐 Browser history viewer
- 🔑 Saved credentials viewer
- 📋 Command reference

## API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/stats` | GET | Server statistics |
| `/api/agents` | GET | List all agents |
| `/api/send` | POST | Send command to agent |
| `/poll` | POST | Agent polling endpoint |

## Deployment

1. Fork or clone this repo
2. Deploy on [Vercel](https://vercel.com)
3. Set framework preset to **Other**
4. Done!
